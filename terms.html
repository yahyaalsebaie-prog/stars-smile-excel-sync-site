Use and responsibility

Terms of Use

Effective date: 17 November 2026

Permitted use

This private desktop utility is intended only for users authorized to access the relevant Google Drive files and Windows destination folders. It is not offered as a public cloud service.

User control

The user authorizes Google Drive access through OAuth and controls the Windows computer where the synchronizer runs. Source Google Drive files remain the designated source of truth. Locally exported XLSX files may be replaced automatically according to the configured schedule, so users should avoid maintaining unsynchronized edits solely in local copies.

Operational limitations

Synchronization depends on Google API access, network connectivity, Windows Task Scheduler, and matching local folders. Google Sheets-to-Excel exports can have differences in some formulas, formatting, or Google-specific spreadsheet functionality. Users should review financial totals and backups before relying on an export for an official reconciliation or financial decision.

Security responsibilities

Users must protect their Google OAuth credentials and Windows account, maintain suitable local backups, and avoid storing confidential business data in publicly shared folders.

Privacy and contact

See the Privacy Policy for details. Contact is available through the support address configured on the Google OAuth consent screen.
