Privacy and Google API user data

Privacy Policy

Effective date: 17 November 2026. This policy explains how Stars Smile Excel Sync handles information when a user authorizes its locally operated Google Drive integration.

1. Purpose and scope

Stars Smile Excel Sync is a desktop synchronization workflow that exports selected Google Drive reconciliation spreadsheets to Excel (.xlsx) files on the authorized user's Windows computer. This website is informational; it does not receive spreadsheet data or provide user accounts.

2. Information accessed

With the user's explicit OAuth authorization, the utility can read Google Drive file names, metadata, and spreadsheet contents permitted by the selected Google Drive scope. The configured synchronization script processes files in the designated Smile/All-Reconciliation folder. The Google API permission may be broader than that folder; access is limited operationally by the script configuration, not by Google's folder-level OAuth restriction.

3. How the information is used

Data is used only to identify the selected reconciliation documents, export them to Excel, store the local copies in the corresponding company folders, create backups before replacing existing files, and generate local operational logs. No unrelated advertising, profiling, or sale of data is part of this workflow.

4. Storage, transmission, and sharing

Google Drive documents are obtained from Google's service using the authorized desktop software. The exported XLSX files, backups, OAuth credentials, and logs are stored on the authorized user's computer, subject to that computer's local security and backup settings. The informational website does not upload, host, or collect the contents of these files. This workflow does not intentionally transfer Google user data to other companies or external servers except as necessary for communication with Google's services.

5. Retention and deletion

Local exports and backups remain on the user's computer until the user deletes them or changes the local synchronization configuration. Log retention depends on the Windows file cleanup settings. The user can remove local files or disable the scheduled task at any time. Revoking OAuth access in the Google Account also blocks future Drive access unless authorization is granted again.

6. Access controls

The intended OAuth scope is https://www.googleapis.com/auth/drive.readonly. This gives read access, not Drive modification permission. OAuth credentials must be protected and should never be pasted into support chats, source-code repositories, or publicly hosted pages.

7. Google API Services User Data Policy

Google user data is used only for the user-facing file synchronization functionality described here, subject to applicable Google API Services User Data Policy requirements, including Limited Use requirements where applicable. Google data is not used for targeted advertising, sold, or transferred for unrelated purposes.

8. Your choices

  • Disconnect or revoke access at any time in the Google Account's third-party connections settings.
  • Stop the local Windows scheduled task to suspend exports.
  • Delete local exports, backup files, and logs through Windows if no longer required.

9. Contact and updates

For privacy questions or requests, contact the application operator using the User support email listed on the Google OAuth consent screen. This policy may be updated if the synchronization behavior changes; the date above will be revised accordingly.

Scope clarification: This site is publicly readable, but no claims, invoices, personal records, OAuth tokens, or Excel workbooks are published here.
