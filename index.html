Private desktop integration

Keep reconciliation spreadsheets accessible in Excel.

Stars Smile Excel Sync is a locally operated utility for an authorized user to export selected reconciliation spreadsheets from their Google Drive to Excel files on their own Windows computer.

01 / CONNECT

Google authorization

With the user's permission, the desktop configuration connects to Google Drive using OAuth.

02 / READ

Selected folder

The scheduled script reads reconciliation spreadsheets from the configured Smile/All-Reconciliation folder.

03 / EXPORT

Local Excel copies

It saves XLSX exports to matching company folders on the user's computer, keeping local backups before replacement.

Designed for a single, controlled workflow

The utility is not a public file-sharing service. It does not provide a web-based login, public dashboard, or a means for other visitors to access spreadsheet contents. This website contains general app information only.

Its intended Google Drive access is read-only; the automated export process does not edit or delete source files in Google Drive. The OAuth permission may technically permit reading other accessible files, but the configured synchronization workflow is limited to the designated reconciliation folder.

Read our Privacy Policy

Data and security

OAuth credentials, local exported workbooks, backups, and synchronization logs are managed on the user's own computer. Access is governed by the permissions granted to Google and by the security of the local Windows account. No spreadsheet content is published on this website.

This page documents a private-use tool. It is not an interface for running the synchronizer.
